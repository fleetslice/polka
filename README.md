# ПОЛКА.

Личная библиотека электронных книг для одного владельца: закидываешь свои файлы, раскладываешь по полкам, читаешь,
видишь прогресс по главам и по книге, выделяешь, пишешь заметки и спрашиваешь ИИ о прочитанном. PWA, интерфейс на русском.

## Куда класть книги

**В сам сайт, а не в репозиторий.** Кнопка «Закинуть книгу» в шапке или экран **05 Облако** — туда можно перетащить
файлы или целую папку. Файл сохраняется на этом устройстве, в памяти браузера (IndexedDB), и читается без интернета.
В git книги не попадают: `.gitignore` отсекает PDF, EPUB, FB2, аудио и архивы.

На экране «Облако» стоит нажать «Запретить браузеру стирать книги» — иначе браузер вправе очистить хранилище,
когда на диске мало места.

## Что работает сейчас

| Область | Состояние |
|---|---|
| Импорт в браузере | EPUB, FB2 / FB2.ZIP, PDF с текстовым слоем, DOCX, ODT, RTF, TXT (автокодировка, cp1251), HTML, CBZ, MP3/M4B |
| Главы | оглавление EPUB (nav / NCX), секции FB2, outline PDF; без оглавления — эвристики по заголовкам, иначе равные части |
| Полка | корешки и обложки, свои полки (создать, переименовать, удалить, переставить), фильтр по формату, сортировка |
| Читалка | позиция, прогресс главы и книги, время до конца по личной скорости, сегментированная полоса, темы, шрифт, поля, прокрутка или страницы (1–2 колонки), озвучка, поиск по книге, закладки, сноски |
| Выделения и заметки | два цвета, цитаты, мысли, теги, `[[ссылки]]`, стена «Поля», экспорт в Markdown и zip для Obsidian, печать в PDF |
| Повторение | карточки из цитат и из ИИ-толкования, SM-2 |
| Поиск | Ctrl+K: названия, авторы, полный текст (BM25 со стеммингом) |
| ИИ | вопрос к библиотеке, толкование книги, пересказ прочитанной главы, чат по выделенному, связи между заметками — потоковые ответы со ссылками на страницы. Нужен `ANTHROPIC_API_KEY` |
| Офлайн | service worker кеширует оболочку, книги и заметки лежат локально |
| Синхронизация | между вкладками — сразу; между устройствами — через Supabase (см. ниже) |

## Чего пока нет

- **MOBI, AZW3, DJVU, DOC, CBR** — нужен серверный конвертер (Calibre), он не написан. Файл отклоняется с объяснением.
- **OCR сканов** — сканы PDF и CBZ открываются постранично с зумом, но текст в них не распознаётся (нет выделений и поиска).
- **Поиск по смыслу** (эмбеддинги + pgvector) — сейчас поиск лексический. Таблица `chunks` в миграции — задел.
- **Облачные папки, Telegram-бот, e-mail, OPDS, Notion** — требуют серверной части с OAuth и секретами; на экране «Облако» помечены как неподключённые.
- **Передача файлов книг между устройствами.** Синхронизируются позиция, прогресс, выделения, заметки, полки и карточки.
  Сам файл нужно закинуть на каждое устройство — запись о книге найдётся по хешу, и прогресс подхватится.
- **Вход в аккаунт Supabase в интерфейсе.** Код синхронизации написан, но экрана входа нет и на живом проекте Supabase он не проверялся.
- **Обложки и метаданные из Open Library / Google Books** — берутся только из самого файла.
- Lighthouse не замерялся.

## Запуск

```bash
npm install
```

```bash
cp .env.example .env.local
```

```bash
npm run dev
```

Сайт откроется на http://localhost:3000. Без переменных окружения работает всё, кроме ИИ и синхронизации между устройствами.

### Переменные окружения

| Переменная | Где | Зачем |
|---|---|---|
| `ANTHROPIC_API_KEY` | сервер | ключ Claude API. Без него ИИ-функции показывают «ИИ не подключён» |
| `POLKA_AI_MODEL` | сервер | модель, по умолчанию `claude-opus-5-5` |
| `POLKA_AI_RATE_PER_MIN` | сервер | лимит запросов к ИИ с одного IP в минуту, по умолчанию 20 |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | сборка | включают синхронизацию между устройствами |

### Docker

```bash
docker compose up --build
```

### GitHub Pages

Workflow `.github/workflows/pages.yml` при каждом пуше собирает статическую версию и выкладывает её на GitHub Pages.
Это хостинг без сервера: маршруты ИИ в сборку не входят, сайт показывает «ИИ не подключён». Всё остальное работает в браузере.

### Netlify

В репозитории есть `netlify.toml`. В Netlify: Add new site → Import an existing project → GitHub → этот репозиторий и ветка.
Команда сборки и папка подставятся сами. Ключ `ANTHROPIC_API_KEY` (если нужен ИИ) задаётся в Site configuration → Environment variables.

### Supabase

Применить `supabase/migrations/0001_init.sql` (таблица `records` с RLS, функция `upsert_record`, приватный бакет `books`),
включить Realtime для `records`, задать две переменные `NEXT_PUBLIC_SUPABASE_*` и пересобрать.

## Проверка

```bash
npm run typecheck
```

```bash
npm test
```

```bash
npm run e2e -- --trace off
```

Unit-тесты (Vitest): парсеры форматов, определение глав, расчёт прогресса и скорости, SM-2, поиск, синхронизация.
E2E (Playwright): загрузка, полки, чтение и восстановление позиции, цитаты и заметки, две вкладки, поиск, доступность (axe, WCAG 2.1 AA).

# Стратегия тестирования

## Пирамида
| Уровень | Инструмент | Что проверяет | Где |
|---|---|---|---|
| Unit | Vitest + jsdom + fake-indexeddb | чистая логика | `tests/unit` |
| Интеграционный | Vitest | импорт → разбор → записи базы (санитизация, длины, смещения) | `tests/unit/parsers.test.ts` |
| E2E | Playwright (Chromium) | сценарии пользователя на собранном сайте | `tests/e2e` |
| Доступность | axe-core в Playwright | WCAG 2.1 A/AA на всех экранах | `tests/e2e/polka.spec.ts` |

Книги в репозитории не хранятся: фикстуры EPUB, FB2, TXT собираются в тестах программно.

## Unit (32 теста)
- **Парсеры:** определение формата по сигнатуре; cp1251; главы TXT по заголовкам и уровни «часть → глава»; авторазбиение без заголовков;
  FB2 (метаданные, вложенные секции, сноски, битый XML); EPUB (пути, nav, склейка файлов, уровни, не-архив); HTML по h1/h2; RTF с кириллицей.
- **Санитизация:** скрипты, обработчики, `javascript:`, внешние картинки.
- **Прогресс:** взвешивание по длине глав, защита от NaN и значений > 1, медианная скорость и отсев сессий, формат времени, серия дней, склонение.
- **SM-2:** интервалы 1 → 6 → ×ease, сброс, нижняя граница ease.
- **Поиск:** стемминг, ранжирование BM25, разбиение на фрагменты без потерь.
- **Синхронизация:** правило last-write-wins, составные ключи, открытие схемы.
- **Экспорт:** Markdown с frontmatter, порядок по книге, теги.

## E2E (10 сценариев)
1. Пустая полка зовёт закинуть книгу.
2. Загрузка: книга на полке, дубликат, неподдерживаемый формат, TXT; вид «Обложки».
3. Полки: создать, переименовать, пустая полка.
4. Чтение: главы в сайдбаре, листание, прогресс, позиция после перезагрузки, сегмент полосы, клавиша T, блок «Продолжить».
5. Цитата и заметка → «Поля», фильтр по тегу, возврат в книгу.
6. Две вкладки: прогресс и цитата появляются во второй без перезагрузки.
7. Без ключа ИИ: вопрос к библиотеке показывает найденные места.
8. Ctrl+K: фраза из текста → читалка с подсветкой.
9. axe: 0 нарушений на `/`, `/reader`, `/notes`, `/book`, `/cloud`.
10. Телефон 390px: нижний таб-бар, нет горизонтальной прокрутки.

## Что не покрыто
- Ответы ИИ с настоящим ключом (маршруты проверены только на отказ без ключа).
- Синхронизация через Supabase между двумя устройствами.
- PDF, DOCX, CBZ, аудио — проверены вручную в браузере, автотестов нет (pdf.js и mammoth не работают в jsdom).
- Постраничный режим «Страницы» и озвучка — проверены вручную.
- Firefox и Safari; Lighthouse; нагрузка на больших библиотеках.

## Запуск
`npm test` · `npm run e2e -- --trace off` · `npm run typecheck`

# Дизайн-система ПОЛКА.

Характер: тёмный, «чернильный», журнальная типографика, огромные заголовки, один яркий акцент.
Нет боковой навигации по сайту, карточек с тенями, градиентов и эмодзи.

Токены — в `src/styles/tokens.css`; `tailwind.config.ts` только ссылается на переменные. Значения в компонентах не хардкодятся
(исключения: цвета тем страницы читалки и цвета корешков — это содержимое, а не интерфейс).

## Цвет
| Токен | Значение | Роль |
|---|---|---|
| `--bg` / `--bg-2` / `--surface` | `#121211` / `#171614` / `#1F1E1B` | фон, панели, поднятые блоки |
| `--line` | `#2A2925` | разделители 1px |
| `--line-2` | `#3A3934` | декоративные обводки, дорожка полосы прогресса |
| `--line-3` | `#77736A` | границы интерактивных элементов |
| `--text` / `--text-2` / `--muted` | `#EDE8DF` / `#C9C4BA` / `#9C978E` | текст: основной, вторичный, служебный |
| `--accent` | `#C8F031` | главное действие, прогресс; текст на нём `--ink` |
| `--accent-2` | `#FF6A3D` | второй цвет выделений |
| `--ink` | `#121211` | текст на акценте и светлых карточках |

Акцент меняется в настройках: `#C8F031`, `#FF6A3D`, `#8FB8FF`, `#F2C14E` — все дают контраст ≥ 7:1 с `--ink`.

**Отступление от макета.** В задании обводка неактивной пилюли — `--line-2`. Её контраст с фоном 1,5:1, что ниже
требуемых 3:1 для границ элементов управления (WCAG 1.4.11). Введён `--line-3` (3,9:1); `--line-2` оставлен для декора.

Контраст текста на `--bg`: `--text` 15,3:1, `--text-2` 10,6:1, `--muted` 6,4:1.

## Шрифты
| Роль | Гарнитура | Применение |
|---|---|---|
| Заголовки, крупные цифры | Unbounded 600 / 800 | hero до 132px, `line-height` 0,92, `letter-spacing` −0,04em, точка акцентом в конце |
| Интерфейс | Golos Text 400 / 500 / 600 | 15px, кнопки 14px |
| Служебные подписи | JetBrains Mono 400 / 600 | 11–12px, прописные, трекинг 0,12em |
| Текст книги | Literata | 19px по умолчанию, интервал 1,65, колонка 680px |

## Отступы, форма, движение
Шаг 4px: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 72. Поля страницы `--gutter` = clamp(16px, 3,4vw, 48px).
Радиус пилюли 22px; остальное прямоугольное. Теней нет — сетки разделяются линиями 1px (`.hairgrid`).
Движение только в ответ на действие: выдвижение корешка 18px за 220мс; `prefers-reduced-motion` отключает.

## Компоненты
| Класс | Что это | Состояния |
|---|---|---|
| `.pill` | кнопка-пилюля, высота ≥ 44px | обычная (обводка `--line-3`), наведение (обводка `--text`), активная `aria-pressed` / `aria-current` / `aria-selected` (фон `--text`, текст `--bg`), `disabled` (45%), фокус (обводка акцентом 2px) |
| `.pill-accent` | главное действие | один на блок |
| `.pill-ghost` | без обводки | пункты меню, действия в плавающем меню |
| `.icon-btn` | круглая кнопка-иконка 44px | обязателен `aria-label` или скрытый текст |
| `.tablink` | моно-фильтр с подчёркиванием акцентом | `aria-pressed` |
| `.hairgrid` | сетка с линиями 1px | — |
| `.bar` | полоса прогресса 3px | заливка акцентом |
| `.field`, `.field-underline` | поля ввода | всегда с `<label>` |
| `.mono`, `.display`, `.dot` | служебная подпись, заголовок, точка акцента | — |
| `SegmentBar` | полоса глав | сегмент — кнопка 44px высотой, подсказка при наведении и фокусе |
| `Spines` / `Covers` | книги на полке | корешок — ссылка; последний слот «+» — кнопка |

## Правила
- Иконки Lucide, обводка 2. Иконка без подписи — только с доступным именем.
- Адаптивность 360–1440+. До 768px меню становится нижним таб-баром; в читалке панели — выдвижные.
- Заголовок экрана — один `h1` с точкой акцента.

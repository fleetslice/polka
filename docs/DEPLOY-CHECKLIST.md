# Чек-лист перед запуском

## Перед выкладкой
- [ ] `npm run typecheck`, `npm test`, `npm run e2e -- --trace off` — зелёные
- [ ] `npm run build` проходит на чистой копии (`npm ci`)
- [ ] Секреты заданы в окружении хостинга, а не в репозитории: `ANTHROPIC_API_KEY`
- [ ] `.env*` в `.gitignore`; в истории git нет ключей
- [ ] `POLKA_AI_RATE_PER_MIN` выставлен; у ключа Claude задан месячный лимит расходов в консоли Anthropic
- [ ] Сайт отдаётся по HTTPS (без него не работают service worker, установка PWA и `crypto.subtle`)

## Supabase (если включается синхронизация)
- [ ] Миграция `supabase/migrations/0001_init.sql` применена
- [ ] RLS включён на `records`, `chunks`, `cloud_sources`; проверено вторым аккаунтом, что чужие строки не видны
- [ ] Realtime включён для `records`
- [ ] Бакет `books` приватный
- [ ] В Auth отключена свободная регистрация (владелец один) либо разрешён только его e-mail
- [ ] Включены ежедневные бэкапы базы (Point-in-Time Recovery на платном тарифе)
- [ ] `NEXT_PUBLIC_SUPABASE_*` заданы до сборки

## Данные владельца
- [ ] В браузере нажато «Запретить браузеру стирать книги»
- [ ] Сделана копия заметок и прогресса («Облако» → «Скачать копию…»)
- [ ] Понятно, что без Supabase данные живут только в этом браузере: очистка данных сайта их удалит

## Наблюдение
- [ ] Healthcheck `GET /api/ai/status` подключён к мониторингу
- [ ] Логи сервера собираются; есть оповещение на рост 429 и 502 от `/api/ai/*`
- [ ] Расход токенов Claude отслеживается в консоли Anthropic

## Откат
- [ ] Предыдущий образ или деплой сохранён и возвращается одной командой
- [ ] Схема IndexedDB менялась? Версии Dexie только повышаются; откат кода на старую версию схемы невозможен —
      новую версию схемы выпускать отдельным релизом после проверки
- [ ] После выкладки: открыть сайт, закинуть книгу, перелистнуть, перезагрузить — позиция на месте

## Известные ограничения на момент запуска
- Лимитер запросов хранится в памяти процесса: при нескольких инстансах лимит умножается.
- Нет Content-Security-Policy.
- Lighthouse не замерялся.

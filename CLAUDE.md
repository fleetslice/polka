# Глобальные правила

## Автокоммит изменений сайта
После каждого успешного изменения кода или создания файлов сайта:
1. Проверь `.gitignore`: в репозиторий не должны попадать PDF, книги (EPUB, FB2, MOBI, AZW3, DJVU, CBZ/CBR и т. п.) и тяжёлые медиафайлы (MP3, M4B, видео, архивы). Если правил не хватает — допиши.
2. Сделай `git add` только нужных файлов.
3. Сделай понятный `git commit` на русском языке (что изменено и зачем).
4. Если в проекте настроен удалённый репозиторий GitHub — отправь изменения через `git push`.
Не коммить, если сборка или тесты сломаны этим изменением.
